  Reuse Detection E2E
  Файл refresh.e2e-spec.ts:

  1. Оставить существующий тест reuse после rotation → 401.
  2. Добавить сценарий с двумя сессиями одного пользователя.
  3. Выполнить rotation в одной из сессий.
  4. Повторно отправить старый токен.
  5. Проверить, что все сессии пользователя отозваны.
  6. Проверить, что все его refresh-токены отозваны.
  7. Добавить отдельный тест, что сессии и токены другого пользователя не
  изменились.
  8. Оставить существующий тест reuse токена после logout → 401.

  Для скрытого состояния сессий и токенов используй repositories. Точные даты
  сравнивать не требуется: достаточно revokedAt !== null у целевых записей и
  revokedAt === null у контрольных. Login и успешный refresh у тебя уже покрывают
  создание сессии, связь токена с ней и обновление lastRefreshedAt.
